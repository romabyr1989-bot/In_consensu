Формат файла импорта

Тот же формат, что у эндпоинта загрузки (FR-4.5). Порядок колонок произвольный, регистр заголовка не важен; разделитель — запятая или точка с запятой, кодировка UTF-8.

Даты

Принимается любая из трёх записей в колонках granted_at и valid_until:

  • 2025-03-12T09:41:00+03:00 — момент с указанием зоны;
  • 2025-03-12 — дата ISO;
  • 12.03.2025 — дата в привычном виде.

Дата без времени читается как начало дня в таймзоне оператора, иначе согласие «сдвинулось» бы на сутки.
